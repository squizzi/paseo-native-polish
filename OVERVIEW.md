Native Polish adds motion to Paseo's desktop and web client: sidebar expansion and collapse, tab opening and closing, pane splitting, closing and maximize/restore, menus and dialogs, button feedback, file tree arrows, tool call and thinking details, agent status changes and new messages. It also makes incoming assistant text feel continuous: web and native drain accumulated provider bursts through a paced reveal queue rather than rendering uneven arrival chunks. It uses the existing Paseo views, including specialized tool output and grouped tools.

Requires Paseo 0.11.2. The desktop and web adapter depends on that version's internal view structure, so later minor versions require a compatibility review. iOS and Android keep their existing motion and add paced assistant-text streaming.

On desktop, hovering at a hidden sidebar's window edge temporarily opens the real sidebar over the canvas without resizing panes. Move away to close it, or press Escape. This has its own setting and works in local and remote workspaces, including alongside HTML previews. While enabled, the corresponding outermost 7 px below the titlebar are reserved for hover activation. Normal sidebar buttons still open the regular layout dock.

Workspace rows fade in when created and fade out when archived. Pinning, unpinning and status-group changes move the existing row smoothly. Project creation/removal animates the group and neighboring rows moving into place. This uses the sidebar motion setting and works in project and status grouping.

Elastic scrolling adds a small damped rebound at the top and bottom of agent conversations, workspace lists, Files, Changes, Markdown previews and editable/read-only file Source views. It has a separate switch and responds to vertical wheel/trackpad and single-finger web touch input. Normal scrolling, horizontal gestures, pinch zoom and nested code/detail scrollers keep their behavior. Source content, line numbers and selection layers move together and restore before editing input. Sandboxed HTML previews are not yet covered; images keep their existing zoom/pan gestures. Native clients retain their existing scrolling.

Supported macOS/iOS browsers use the platform rebound. The desktop fallback follows input directly and returns quickly after release; it approximates the effect because Paseo's Electron window does not expose native scroll bounce to a client plugin.

Open Native Polish in the sidebar to enable or disable each category and choose a gentle or quick pace. Button and status feedback uses shorter transitions. New messages fade in once near the bottom of the conversation. Streaming text is released from a paced queue while a turn is active; completion hands the stable row back to Paseo's renderer for its native Markdown, selection, copy, duration, and fork controls. System Reduce Motion turns off the added animations. Preferences are stored in this client's local storage.

Native Polish uses its own compact Markdown renderer while an assistant turn streams. This is a temporary compatibility workaround until Paseo exposes its host Markdown renderer and streaming lifecycle to plugins upstream. Completion returns the stable row to Paseo's native renderer and full footer. The live renderer ports Paseo's chat Markdown type, default UI/mono font stacks, spacing, block splitting, syntax-token colours, and visual rules for headings, paragraphs, bullet/numbered/task lists, block quotes, horizontal rules, fenced and inline code, emphasis, strike-through, links, standalone images, tables, and `<details>` blocks. On web it mirrors active syntax and prose metrics from already-rendered native Markdown. Paseo-specific Markdown extensions may still differ while the turn is live.

The client observes layout changes and briefly copies visible content locally for exit animations. Copies cannot receive input or accessibility focus and are removed after the transition. The plugin sends no content to a service and contributes no daemon backend.
